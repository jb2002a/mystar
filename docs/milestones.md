# MVP 마일스톤 (6주)

SDK 직접 구현 기준. LangChain/LangGraph 없이 공식 LLM SDK + Pydantic + FastAPI.

---

## Milestone 0 — 설계 고정 (2~3일)

**목표:** "무엇을 절대 하지 않을지"를 코드 계약으로 확정

- [x] 지원 시나리오 확정: 알람, 전화, SMS/카카오톡 메시지
- [x] 2차 확장 범위 확정: 금융 관련 영역을 제외한 일반 앱 열기 및 제한적 조작
- [x] 금지 범위 확정: 금융·결제·OTP·비밀번호·권한 변경·삭제·설치
- [x] 최소 도구 범위 확정: `observe_screen`, `screen_action`, `input_text`, `speak`
- [x] 사용자 확인 및 금융·인증 화면 중단 원칙 확정

**산출물:** [M0 범위 및 도구 계약](milestone-0.md)

---

## Milestone 1 — Android 음성 인터페이스 (1주)

**목표:** 음성 명령을 받고 사용자가 진행 상태를 이해

- [ ] Kotlin + Compose 기본 앱
- [ ] `SpeechRecognizer`로 음성 → 텍스트
- [ ] `TextToSpeech`로 처리 상태·확인 질문 안내
- [ ] "시작 / 취소 / 예 / 아니오" 음성 명령 처리
- [ ] 큰 글자, 고대비, 단일 핵심 버튼 UI

**완료 기준:** "내일 8시 알람 맞춰줘"를 말하면 텍스트가 표시되고 음성으로 재확인

---

## Milestone 2 — 백엔드 Agent SDK 루프 (1주)

**목표:** 자연어를 제한된 도구 호출로 변환

- [ ] FastAPI + 공식 LLM SDK + Pydantic
- [ ] 작업 세션 API: 시작, 화면 관찰 전달, 실행 결과 전달, 확인 응답
- [ ] LLM tool calling으로 다음 행동 하나만 결정
- [ ] 최대 단계 수·타임아웃·반복 탐지
- [ ] 구조화된 감사 로그, 민감 정보 마스킹

**완료 기준:** 모의 Android 도구 환경에서 명령 20개를 허용 도구 호출로 안정 변환

---

## Milestone 3 — 안전 정책 엔진 (4~5일)

**목표:** 모델 오류가 있어도 위험 작업이 실행되지 않음

- [ ] 서버 PolicyEngine: 도구·앱·화면·행동별 허용 여부
- [ ] Android 측 정책: 서버 요청 재검증 (이중 방어)
- [ ] 금융/인증 앱 패키지 및 화면 키워드 차단
- [ ] 전화·메시지 전송은 확인 토큰 없이 불가
- [ ] 정책 우회·프롬프트 인젝션·반복 호출 테스트

**완료 기준:** 차단 시나리오가 모든 계층에서 실행되지 않고 명확히 종료

---

## Milestone 4 — 공식 Android 기능 연동 (1주)

**목표:** Accessibility 없이도 유용한 첫 작업 제공

- [ ] 알람/타이머 생성 (Intent)
- [ ] 연락처 검색 + 전화 발신 (Intent)
- [ ] SMS 작성 (Intent)
- [ ] 지도·카카오톡 등 앱 실행
- [ ] 최종 실행 전 수신자/내용 TTS 확인

**완료 기준:** 실제 갤럭시에서 알람·전화·SMS 시나리오를 확인 절차 포함해 완료

> **첫 세로 슬라이스:** "딸에게 전화해" → 후보 확인 → '예' → 발신 → 결과 안내

---

## Milestone 5 — AccessibilityService ReAct (1~1.5주)

**목표:** 허용된 앱의 제한적 화면 자동화

- [ ] `AccessibilityService` 활성화 및 권한 온보딩
- [ ] 정제된 UI 상태 추출 (앱명, 클릭 가능 요소, 입력 필드)
- [ ] `tap`, `input_text`, `scroll`, `back` 구현
- [ ] 카카오톡 1개 플로우만 우선 지원
- [ ] 화면 탐색 최대 횟수, 중복 화면 탐지, 안전 중단

**완료 기준:** 신뢰 연락처에게 메시지 작성 → 최종 확인 → 전송. 실패 시 전송 없이 중단

---

## Milestone 6 — 현장 테스트·보완 (1주)

**목표:** 실제 시니어 사용에서 실패를 이해하고 복구

- [ ] 3~5명 관찰 테스트
- [ ] 발화 실패, 동명이인, 잘못 들은 메시지, 앱 UI 변경 테스트
- [ ] 음성 재질문·취소 UX 개선
- [ ] 실패 원인별 로그 분석 및 정책 보강
- [ ] Google Play 접근성 정책·개인정보 처리 방침 검토

**완료 기준:** 핵심 시나리오 성공률 80% 이상, 위험 작업 자동 실행 0건
