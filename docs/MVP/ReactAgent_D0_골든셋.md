# D0 골든셋 (6개)

홈 **목표** 칸에 넣고 실행. `{contact}`는 테스트용 카톡 상대 이름.

| # | 쿼리 | 결과 |
|---|---|---|
| 1 | 오늘 서울 날씨 알려줘 | `web_search`로 답하고 TTS. 구글/크롬 안 열림 |
| 2 | 설정 열어서 배터리 몇 퍼센트인지 알려줘 | 배터리 화면 %를 summary에 말함 |
| 3 | 설정에서 접근성 열어줘 | 접근성 화면까지 (스크롤 필요하면 스크롤) |
| 4 | 설정 배터리까지 들어갔다가 나와줘 | 배터리 들어간 뒤 `back`으로 설정 상위 |
| 5 | 카카오톡에서 {contact}한테 테스트메시지D0 보내줘 | 전송 전 confirm 승인 후 실제 전송 |
| 6 | 카카오톡에서 {contact} 마지막 메시지 읽어줘 | 채팅 마지막 말을 summary에 말함 (전송 없음) |

**#6 전제:** `{contact}` 채팅 마지막 메시지가 `골든읽기D0`이어야 함.
