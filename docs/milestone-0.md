# Milestone 0 — 범위 및 도구 계약

## 목적

MVP가 수행할 작업과 수행하지 않을 작업, 그리고 에이전트가 Android에 요청할 최소 도구 범위를 확정한다.

이 문서는 구현 세부 로직, API 형식, 화면 요소 스키마를 정의하지 않는다. 해당 사항은 후속 마일스톤에서 구체화한다.

## 지원 범위

### 1차 지원 시나리오

- 알람 설정
- 전화 발신
- SMS 메시지 작성 및 전송
- 카카오톡 메시지 작성 및 전송

### 2차 확장 범위

- 금융 관련 영역을 제외한 일반 앱 열기
- 금융 관련 영역을 제외한 일반 앱의 제한적 화면 조작

## 금지 범위

다음 영역은 1차와 2차 모두에서 AI가 자동으로 조작하지 않는다.

- 금융, 결제, 송금, 주식, 보험
- 비밀번호, OTP, 생체인증, 인증서 등 인증 절차
- 권한, 보안 설정 변경
- 앱 설치 및 삭제

금융 또는 인증 관련 앱·화면이 감지되면, 현재 작업은 실행하지 않고 중단한다.

## 최소 도구 계약

에이전트가 Android에 요청할 도구는 아래 네 가지로 제한한다.

| 도구 | 책임 |
|---|---|
| `observe_screen` | 현재 앱과 화면의 조작 가능한 상태를 읽는다. |
| `screen_action` | 화면 요소를 선택·탭하고, 스크롤하거나 뒤로 이동한다. |
| `input_text` | 지정된 입력 필드에 텍스트를 입력한다. |
| `speak` | 진행 상태, 확인 질문, 결과를 음성으로 안내한다. |

자유 좌표 기반 조작이나 셸 실행 같은 범용 제어 도구는 제공하지 않는다.

## 안전 원칙

- `screen_action`과 `input_text`는 정책 검증을 통과한 화면에서만 실행한다.
- 금융·인증 화면에서는 네 도구 모두 작업 진행 목적으로 사용하지 않는다.
- 전화 발신과 SMS·카카오톡 메시지 전송은 사용자 확인이 완료된 경우에만 실행한다.
- `speak`로 사용자에게 진행 상태와 확인 질문을 전달한다.

## M0 완료 기준

- 1차 지원 시나리오와 2차 확장 범위가 팀 합의로 확정되어 있다.
- 금지 범위가 위 목록으로 명시되어 있다.
- 에이전트 도구가 네 가지로 제한되어 있다.
- 전화·메시지 전송의 사용자 확인 원칙과 금융·인증 화면 중단 원칙이 확정되어 있다.
