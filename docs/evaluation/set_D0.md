# D0 골든셋

평가 큐가 읽는 **원본**이다. 셋을 바꿀 때는 이 파일만 고친다.
빌드하면 이 파일이 그대로 `assets/eval/set_D0.md`로 복사되고, 앱은 아래 `tasks` 블록의
번호 목록만 파싱해서 순서대로 돌린다.

- 번호 순서가 `task_index`다. 줄을 넣거나 지우면 이후 번호가 밀린다
- `tasks` 블록 **밖의** 번호 목록은 파싱되지 않는다. 설명은 자유롭게 써도 된다
- 앱에서 목록을 편집하면 그 실행에만 적용되고, `원본 불러오기`로 이 파일 상태로 되돌아간다
